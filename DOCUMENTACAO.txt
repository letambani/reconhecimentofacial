2. VISÃO GERAL
--------------------------------------------------------------------------------

Este projeto é uma aplicação web de reconhecimento facial que roda inteiramente
no navegador do usuário. Não há servidor backend dedicado ao processamento de
imagens: a detecção e a correspondência de rostos são feitas localmente com
modelos de inteligência artificial carregados via face-api.js.

A interface foi pensada para uso institucional, com cabeçalho e rodapé
referenciando a PMSC, e permite:

  - Consultar se uma pessoa capturada pela câmera ou enviada por arquivo já
    está cadastrada na base de rostos conhecidos;
  - Identificar múltiplos rostos em uma mesma imagem;
  - Cadastrar rapidamente pessoas desconhecidas durante uma consulta.

Os dados de pessoas cadastradas ficam em memória durante a sessão. Novos
cadastros feitos pelo usuário são adicionados à base em tempo real, mas não
são persistidos em banco de dados ou armazenamento local após recarregar a
página.

4. ARQUITETURA DA APLICAÇÃO
--------------------------------------------------------------------------------

A aplicação segue uma arquitetura SPA (Single Page Application) com a lógica
principal dividida em camadas:

  [Interface]  Index.tsx, CameraCapture, QuickRegister
       |
  [Hook]       useFaceRecognition.ts — carrega modelos, monta base, faz matching
       |
  [Biblioteca] face-api.js — detecção e descritores faciais
       |
  [Dados]      persons.ts — lista inicial de pessoas com fotos

Fluxo de estados da tela principal (Index.tsx):

  camera  -->  result   (quando nenhum rosto é detectado)
     |
     +----->  register  (quando o usuário escolhe cadastrar pessoa desconhecida)

Durante o estado "camera", após uma captura com rostos detectados, os
resultados são exibidos abaixo da câmera sem mudar de tela.

5. FUNCIONALIDADES DETALHADAS
--------------------------------------------------------------------------------

5.1 Captura pela câmera
  - Acesso via WebRTC (navigator.mediaDevices.getUserMedia)
  - Suporte a câmera frontal (user) e traseira (environment)
  - Detecção automática quando o dispositivo possui apenas uma câmera
  - Resolução ideal: 640x480
  - Botão para reiniciar o stream da câmera

5.2 Envio de imagem
  - Formatos aceitos: JPG, JPEG, PNG, WEBP
  - Validação por MIME type e extensão do arquivo
  - Pré-visualização da imagem enviada no quadro de análise

5.3 Detecção e identificação de rostos
  - Detecção de múltiplos rostos por imagem (detectAllFaces)
  - Caixas delimitadoras (bounding boxes) desenhadas sobre o vídeo/imagem:
      * Verde  = pessoa identificada
      * Vermelho = pessoa desconhecida
  - Exibição do nome e percentual de compatibilidade sobre cada rosto
  - Lista resumida abaixo da câmera com detalhes de cada resultado

5.4 Cadastro rápido
  - Disponível para rostos não identificados
  - Campos: nome completo (obrigatório) e observações (opcional)
  - A foto capturada é associada ao novo cadastro
  - O descritor facial é calculado e incluído na base em memória

5.5 Base inicial de pessoas
  - 12 pessoas pré-cadastradas com fotos em src/assets/persons/
  - Nomes: Henrique, Isabella, Issaga, Leandro, Leonardo, Letícia, Luciano,

6. ALGORITMO DE RECONHECIMENTO FACIAL
--------------------------------------------------------------------------------

O face-api.js utiliza redes neurais pré-treinadas para:

  1. Detectar rostos na imagem (SSD MobileNet v1)
  2. Localizar 68 pontos de referência facial (landmarks)
  3. Gerar um vetor descritor de 128 dimensões (face descriptor)

A correspondência entre rostos é feita pela distância euclidiana entre os
descritores. Quanto menor a distância, mais semelhantes são os rostos.

Parâmetros configurados (src/lib/faceDescriptorSimilarity.ts):

  FACE_MATCH_DISTANCE_THRESHOLD = 0.6
    - Limiar para considerar um match válido
    - Distâncias abaixo de 0.6 indicam correspondência no banco
    - Faixa típica para a mesma pessoa: ~0,15 a 0,5

  Percentual de compatibilidade exibido na interface:
    - Conversão não linear da distância euclidiana para 0–100%
    - Referência de exibição: 0.88
    - Curvatura (gamma): 0.28
    - Fórmula: 100 * ((ref - d) / ref) ^ gamma
    - Objetivo: apresentar percentuais mais intuitivos ao usuário

Carregamento dos modelos (useFaceRecognition.ts):
  1. Tenta carregar de public/models/ (local, no deploy)
  2. Se falhar, usa CDN do repositório oficial do face-api.js no GitHub

8. COMO INSTALAR E EXECUTAR
--------------------------------------------------------------------------------

Requisitos:
  - Node.js 18 ou superior
  - Navegador com suporte a WebRTC (getUserMedia) para uso da câmera
  - Conexão com internet na primeira carga (se modelos locais não existirem)

Instalação:

  npm install

Desenvolvimento:

  npm run dev

  A aplicação abre em http://localhost:8080

Build de produção:

  npm run build

  Gera a pasta dist/ com index.html, 404.html e .nojekyll (GitHub Pages)

Preview do build:

  npm run preview

Outros comandos:

  npm run lint        Verificação ESLint
  npm test            Testes unitários (Vitest)
  npm run test:watch  Testes em modo watch

11. MODELO DE DADOS
--------------------------------------------------------------------------------

Interface Person (src/data/persons.ts):

  id: string              Identificador único
  name: string            Nome completo
  imageSrc: string        URL ou data URL da foto
  notes?: string          Observações opcionais
  registeredAt: string    Data de cadastro (YYYY-MM-DD)
  additionalPhotos?: string[]  Fotos adicionais (campo reservado)

Durante o runtime, cada pessoa também possui um descritor facial (Float32Array
de 128 elementos) armazenado em memória no hook useFaceRecognition.


--------------------------------------------------------------------------------
12. LIMITAÇÕES E CONSIDERAÇÕES
--------------------------------------------------------------------------------

  - Dados não persistem: cadastros feitos na sessão são perdidos ao recarregar
  - Processamento 100% client-side: performance depende do dispositivo
  - Qualidade da identificação varia com iluminação, ângulo e resolução
  - O percentual exibido é uma escala visual, não probabilidade estatística
  - Requer permissão de câmera no navegador
  - Modelos de IA têm tamanho considerável (~vários MB) na primeira carga
  - Projeto acadêmico — não substitui sistemas biométricos certificados
